# Dictax

Voice-to-text web app (PWA) in Italian. The owner (non-technical) asks for changes in chat; Claude edits the code and pushes to `main`. Cloudflare Pages deploys `main` automatically (GitHub app access fixed on 2026-11-14; if a push does not show up, trigger a deploy via the Cloudflare API: POST `/accounts/{id}/pages/projects/dictax/deployments` with an empty form). Write replies to the owner in Italian, plain language, no jargon.

## Stack
- `public/index.html`: the whole front end (single file: HTML, CSS, JS). No build step, no framework.
- `functions/api/*.js`: Cloudflare Pages Functions. `transcribe.js` (Workers AI Whisper, `env.AI`), `ai.js` (Claude via `@anthropic-ai/sdk`, key in secret `ANTHROPIC_API_KEY`), `health.js`.
- `lib/util.js`: shared helpers (JSON responses, optional `ACCESS_CODE` gate via `x-access-code` header).
- `wrangler.toml`: Pages config (source of truth for bindings and vars; secrets live in the Cloudflare dashboard).
- Data is in `localStorage` (prefix `dx1_main_`), synced to Supabase when signed in.
- Supabase project `dictax` (ref `kzrxedaahwgltzrbuctl`, eu-west-1): email sign-in (magic link or 6-digit code, no password) via supabase-js UMD loaded on demand; table `public.user_data(user_id,key,value jsonb,updated_at)` with RLS own-rows. The `raw.set` hook marks `SYNC` keys dirty and pushes (for `main_clients` it pulls first: `syncAll`); `main_clients` is merged per client on pull (newer `up` wins, but a positioning, ideas or dritte are never replaced by an empty value); `saveClient` never overwrites an existing positioning with an empty box, and "Genera il posizionamento" restores the previous text if generation fails; pull merges `main_notes`/`main_money` by id (newer `up` wins, tombstones in `main_dels`), other keys last-write-wins. Account button `#accBtn` top right, view `#v-account`.

- **🔔 Promemoria on notes** (any note type): `n.rem={at:"YYYY-MM-DDTHH:MM" local, done, nt?, auto?}`. Detail: "🔔 Promemoria" button (`#remBtn`, next to Condividi/Fatto) opens `#remSheet` (`openRem`): quick chips (Tra 1 ora, Stasera/Domani alle 18, Domani alle 9, Lunedì alle 9) or `datetime-local`, Salva (asks Notification permission), "📅 Mettilo anche nel calendario del telefono" (`remIcsFor`, .ics with alarm: the only way to be alerted with the app closed, no push server), "Togli promemoria". - **Fatto vs Pubblicato**: content status `n.st` is idea / lavoro / fatto (= pronto da pubblicare) / **pubblicato** (= online). `ST`, `ST_C` (pubblicato blue `#2f6fdb`), helpers `isPub(n)` and `isFatto(n)` (fatto or pubblicato).
