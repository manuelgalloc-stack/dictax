# Dictax

Voice-to-text web app (PWA) in Italian. The owner (non-technical) asks for changes in chat; Claude edits the code and pushes to `main`. Cloudflare Pages deploys `main` automatically (GitHub app access fixed on 2026-11-14; if a push does not show up, trigger a deploy via the Cloudflare API: POST `/accounts/{id}/pages/projects/dictax/deployments` with an empty form). Write replies to the owner in Italian, plain language, no jargon.

## Stack
- `public/index.html`: the whole front end (single file: HTML, CSS, JS). No build step, no framework.
- `functions/api/*.js`: Cloudflare Pages Functions. `transcribe.js` (Workers AI Whisper, `env.AI`), `ai.js` (Claude via `@anthropic-ai/sdk`, key in secret `ANTHROPIC_API_KEY`), `health.js`.
- `lib/util.js`: shared helpers (JSON responses, optional `ACCESS_CODE` gate via `x-access-code` header).
- `wrangler.toml`: Pages config (source of truth for bindings and vars; secrets live in the Cloudflare dashboard).
- Data is in `localStorage` (prefix `dx1_main_`), synced to Supabase when signed in.
- Supabase project `dictax` (ref `kzrxedaahwgltzrbuctl`, eu-west-1): email sign-in (magic link or 6-digit code, no password) via supabase-js UMD loaded on demand; table `public.user_data(user_id,key,value jsonb,updated_at)` with RLS own-rows. The `raw.set` hook marks `SYNC` keys dirty and pushes; pull merges `main_notes`/`main_money` by id (newer `up` wins, tombstones in `main_dels`), other keys last-write-wins. Account button `#accBtn` top right, view `#v-account`.

## Product rules
- One app with a **Creator** switch: the base (Note) has the standard formats, styles and folders; turning Creator on adds social formats, extra styles, content folders and the brand-voice tab. Notes are shared (storage prefix `dx1_main_`).
- Keep the UI simple and large (big buttons and icons); advanced settings ("⚙️ Impostazioni", `#styleBox`: clients toggle, "Correggi la lingua" toggle (`dx1_lang`, default on: `langRule()` is appended to every rewrite and to-do prompt to fix grammar, spelling, punctuation and misheard words), AI-sentence check off by default, red-date days, Semplice/Elaborata, style, length) live in the profile view, not on the home. Going home is always obvious: the Dictax logo (`#brandHome`) and the big green "Tutte le note" button (`.homeBtn`) at the top of detail, calendar and profile.
- Desktop (>=980px): two columns, recorder/composer on the left (sticky, `.homeLeft`), notes in a card grid on the right (`.homeRight`). Phone layout unchanged.
- First open shows `#welcome` ("Come userai Dictax?": Uso personale / Creator singolo / Creator con clienti), saved as `uso` and changeable from the profile; `setUso()` sets mode and `ckind`.
- Creator has two kinds (`ckind`, segment `#kindSeg` in the profile view `#v-account`, opened by the top-right button): **Creator singolo** (`solo`: body `.solo`, clients hidden, the Clienti tab becomes "Brand" with the creator's own positioning stored as profile `__me`, used via `ctxFor()` in every social prompt) and **Gestisco clienti** (`agency`, default). In Chiedi, agency mode shows `#qClient` to pick a client: context is limited to that client's notes plus its positioning, and content requests use the ManuLab voice.
- Client choice is by tap: `cliChips(input,onPick)` shows "Nessuno", the most used clients (max 12) and "+ Nuovo" (reveals the text input) in the "Che cos'è?" sheet and in the note detail.
- Home is minimal: recorder ("Ricomincia" visible only when there is something to restart), text box, "Crea nota", notes; example notes disappear once there are 3 own notes. Dock: Note, Chiedi, Conti (+ Clienti/Brand in Creator); "Unisci" is no longer a tab (Chiedi can merge). Note detail: type as coloured chips (`#dTypeChips`), one "📤 Condividi" button (Web Share, else copy); small "Scarica file" (.md) and "Elimina nota" side by side at the very bottom. "Crea anche" shows only 4 chips (content: 5 ganci, reel, carosello, newsletter; notes: email, riassunto, verbale, to-do) plus a dashed "Altro…" that reveals the rest. Client form shows name + "Di cosa si occupa" + pack; pubblico/offerta/zona/da evitare sit in a closed "Altri dettagli (facoltativi)" (`#cliMore`, opens when filled). "Voce di brand" is a closed `<details>` at the bottom of the Clienti tab. In the home list, swiping a card right-to-left (touch) reveals a red "Elimina" button (`swipeable()`, `deleteNote()`); tapping it deletes. A long press (550 ms) opens the `#delAsk` sheet ("✓ Fatto" or "↩︎ Riapri" / "Elimina" / "Annulla"). "Fatto" (internally archive): `n.arch` (`setArch()`); archived notes leave the home list (still in calendar, search and Chiedi); only a red-outlined "✓ Note fatte (N)" button at the end of the list (`.archBtn`) toggles `showArch` (no chip in the filters: too invasive); the detail view has a red-outlined "✓ Fatto" button next to Condividi, hidden on content notes (they use the Idea/In creazione/Fatto status instead). Choosing **Nota** skips the "Come la scrivo?" step and uses the remembered level.
- Recordings are never lost: `transcribe(blob,key)` first saves the audio in IndexedDB (`dictax-audio`, helpers `audSet/audGet/audDel/audTrim`) and lists it in `dx1_audioPend`; on failure the home shows `#pendBox` ("🔁 Trascrivi ora", auto-retry on `online`). The note keeps `n.audio` and the detail shows "🎧 Audio originale" (device only, last 40 kept).
- To-do tasks can have a due date `x.due` (AI extracts it from "venerdì", "domani"…). Deadlines are a Creator-only feature: the 📅 chip (set/change, red if late, yellow today) and the 🔔 .ics button (`downloadIcs`) show only in Creator mode, and deadlines appear only in the calendar as hollow circles ("○ Scadenza", red outline if late) with rows in the day list. Anything past its date and not done turns red in the calendar (content diamond, deadline circle filled red), legend "■ Scaduto". No "Oggi" box on the home (`renderToday` is disabled on purpose).
- Calendar client picker (agency, when clients exist): horizontal chips `#calCli` "Tutti i clienti" + each client (`calCli`, remembered as `dx1_calCli`); the grid, legend, day list, free slots and deadlines show only that client, and "+ Contenuto per questo giorno" presets it. Calendar: tapping today or a future day shows "+ Contenuto per questo giorno" (`setPlan`): a purple banner on the composer, and the next content gets that `pub` date (status In creazione; Manuale → Idea if in the future).
- Carousel: "Quante slide?" (2 to 10, `carN`) when Carosello is selected; the prompt ends with a "CONSIGLI GRAFICI" section (photo/graphic per slide).
- First-use guide `#guide` (3 steps) after the welcome choice; "Rivedi la guida" in the profile. Profile also has "Scarica tutti i miei dati" (JSON), "Privacy e termini" (`/privacy.html`) and "Elimina tutti i miei dati" (deletes Supabase rows + local data + audio).
- Clients are optional: toggle "Usa i clienti" in Impostazioni (`dx1_useClients`, default on); off adds `body.noClients`, which hides every `.cliOpt`.
- **Conti** tab (both modes): income/expenses in `store` key `money` ([{id,k:in|out,v,c,t,d}]), month switcher, 6-month SVG bar chart, expenses by category, AI tips button. "Sono in regime forfettario" card (`store` key `forf` {on,rate 5|15,coef 78,inps 26.07}, synced as `main_forf`): per income `forfPart(v)=v×coef×(inps+(1−inps)×rate)`, shown under each income row ("Da mettere da parte"), after adding an income, and as totals for the month and from the start of the year; coefficient and INPS editable under "Coefficiente e contributi"; labelled as an estimate.
- **Clienti** tab (Creator; the old Voce view, brand voice stays below): client profiles in `store` key `clients` ({name:{niche,target,offer,zone,avoid,pos,up}}); "Genera il posizionamento" builds a ManuLab positioning (north-star, pillars, tone, words, TOFU/MOFU/BOFU ideas); `clientCtx(cl)` injects it into social content prompts. "Trova le idee" extracts 6 TOFU/MOFU/BOFU ideas (saved in the profile `ideas`); "Crea il contenuto" makes a Contenuto note for that client with status In creazione.
- Content notes marked Fatto are faded (`.doneC`, opacity .5) and moved to the bottom of the home list; faded also in the calendar day list. Content notes have a status `n.st` (idea/lavoro/fatto) and publish date `n.pub` (YYYY-MM-DD), set in the detail view; "Fatto" sets today if empty. `#v-cal` month calendar (button `#calOpen`, Creator only) shows contents on their publish date as diamonds (yellow In creazione, green Fatto, grey Idea), plus notes and to-do lists on their creation date as plain black dots (`calDate()`).
- Content creation picks a platform first ("Per quale piattaforma?": `PLATFORMS` Instagram/Facebook/TikTok/LinkedIn, remembered as `cplat`) then its formats ("Cosa creo?": e.g. Caption, Carosello, Reel), then one "✨ Crea contenuto" button (`#contentGo`): no Semplice/Elaborata question for content, social formats always use the `completa` level plus the ManuLab voice. A second button "✍️ Manuale" (`#contentPlain`) saves the text as-is (no AI), `plain:true`, status Fatto, publish date today, tags = platform + chosen formats. Other social formats (ganci, newsletter, idee, piano) are offered afterwards in "Da questo contenuto crea anche", listed first for content notes.
- Creation flow: record (or type) -> the "Che cos'è?" sheet asks the type: **Nota** (green, clean text), **Contenuto** (purple, social formats; Creator only) or **Link utile** (orange). The sheet always shows (Nota, Contenuto in Creator, Link utile). **To-do is no longer a type**: inside any non-content note, the detail view shows "☑️ Crea la lista delle cose da fare" (`.todoMake`, `makeTodo()`), which extracts `n.tasks=[{t,done,due?}]` into a checklist card below the text (tick/add/delete); `hasTodo(n)` = has `n.tasks` or `out.todo`; home cards show a "☐ 2/5" pill; "Aggiungi alla nota" also adds tasks found in the addition. Old `type:"attivita"` notes are read as Nota with their list. "Come la scrivo?": **Semplice** (`leggera`, only removes hesitations, default) or **Elaborata** (`completa`); remembered, old `media` maps to `completa`. Optional **Cliente** per note; the home list filters by type, by client (dropdown) and by tag: tapping a #tag in the note detail (`.tagBtn`) goes home filtered by that tag (`setTag()`), shown as a green chip "#tag ✕" (`#tagChip`, tap to clear); tapping a tag on a home card does the same; long press (700 ms) on a tag in the detail asks to remove it. No dropdown for tags. No folders.
- **Pacchetti** (Creator only, optional per client): in the client form, "📦 Pacchetto" box with "Contenuti al mese" (`p.n`, 0 = none) and optional weekday chips (`p.days`, 0=Mon…6=Sun; none → weekdays Mon–Fri spread over the month). `packSlots/packInfo/packFree` compute the month's slots; a slot is free if no content of that client has that `pub` date, and only the remaining `n − done` future slots are shown. Calendar: dashed hollow diamonds `i.c.free` ("Da riempire N" in the legend) and day-list rows "◇ Posto libero · Cliente" with "+ Crea" → `setPlan(date, client)` (banner shows client, the sheet preselects it via `planCli`). Clienti list: "X di N questo mese" bar under each client, red when behind the month's pace. "Una settimana di contenuti" for a client with a pack uses its free slots as dates. Solo creator uses profile `__me` (contents with no client). Clients without a pack behave as before.
- No TOFU/MOFU/BOFU in the UI: `faseLbl()` shows "Farsi conoscere" / "Creare fiducia" / "Vendere" (week tags, client ideas; the positioning prompt asks for these words). Old data is migrated at startup (`fixFasi()`): TOFU/MOFU/BOFU tags, saved idea phases and words in saved positionings become the plain labels, and old content notes get their format tag; tag pills also display through `faseLbl()`. Every content note gets its format as a tag (`fmtLabel()`: Reel, Carosello, Caption, Post…), also in the week plan (tags = platform, format, purpose).
- **Content tools** (content notes only, in `#dStBox`, Apple-simple): Reel scripts start with a "3 GANCI" section (3 short alternative hooks) and then a "SCRIPT" section that develops the best one, in very simple words. "🎬 Gobbo" opens `#gobbo` (showing only the SCRIPT part when present), a full-screen black teleprompter of the reel script (or `mainKey(n)`), hashtag/keyword lines removed, [cues] in grey, ▶/❚❚ auto-scroll, −/+ speed (`dx1_gSpeed`), wake lock. "✅ Controlla" asks the AI for a ManuLab pagella (`n.check={voto,gancio,pos,cta,consiglio,k}`) shown as `.checkCard` with "✨ Sistemalo tu" (`fixContent`). When status is Fatto, "Com'è andato?" 🔥 Bene / 😐 Così così sets `n.res` (top/meh); `perfCtx(client)` injects the client's best contents (and titles of weak ones) into every social prompt, the fix and the week plan. In the content sheet, "📅 Una settimana di contenuti" (`#contentWeek`): a quick AI pass first reads the note; if the author lists specific contents (with optional format and day), it writes exactly those (same order), otherwise it proposes a balanced set (farsi conoscere / fiducia / vendere). Count: listed items, else the client's pack slots in the week (start = planned day or tomorrow, 7 days), else 5. If the client has a pack and the listed count differs from its weekly slots, `askChoice()` (`#choiceAsk` sheet) asks "Fai tutti e N / Fai solo i primi W" or "Fai solo questi / Aggiungi tu gli altri". Dates: the day said in the note, else the pack's next free slots, else spread over the week. Status In creazione, then opens the calendar.
- **Dritte del momento** (owner-only guidance for all users): Supabase table `public.dritte(id,settore,testo,attiva,updated_at)`, public read of active rows (anon REST fetch with the publishable key, cached in `dx1_dritte`, refreshed hourly); writes only for admins (`public.admins(user_id)`, `public.is_admin()` security invoker). `dritteCtx()` injects active dritte into every social prompt, the pagella, the fix, the week plan, client ideas and Chiedi content; the AI applies only those for "Tutti" or the client's sector. Admin UI `#admBox` ("🧭 Dritte del momento", in the profile when signed in as an admin): edit sector/text (autosave), Attiva/Spenta toggle, delete, "+ Nuova dritta" (created off). Claude can also edit them via SQL.
- **Link utili**: type `link` (orange `--t-link`), third button "🔗 Link utile" in the "Che cos'è?" sheet (where To-do used to be). It opens `#linkSheet` prefilled with the URL found in the text and the rest as title (URL field with "📋 Incolla" via clipboard, "Di cosa si tratta?" title; empty title → domain). A bare URL in the text box goes straight to `#linkSheet` on "Crea nota". Note shape `{type:"link",out:{link:url},tr:url,title}`; detail shows `linkCard()` (Apri il link, Copia, editable title and URL) and hides transcript tab, "Crea anche", "Aggiungi alla nota" and the type row (`body.isLink`). The "Link" filter chip appears only when a link exists. Links have tags too: "Tag (facoltativo)" field `#lTags` in the sheet and a "Tag" field in `linkCard()` (comma/space separated, `parseTags()`, lowercase, no #), with tap-to-add chips of the most used tags (`tagSuggest()`); they work with the tag filter like any note.
- **Creator Pro** (free for now, flag `CREATOR_PRO`): every social content (captions, scripts, carousels, ganci...) is written with the `MANULAB_VOICE` rules (Triplo Gancio method) by default, via `useML(k)`. The old "Riscrivi con la voce ManuLab" button is hidden (`if(false&&...)`); re-enable it if the voice becomes a paid extra.
- Each note shows its date and age ("3 giorni fa"); it turns red after N days without progress (setting in "Altre opzioni", default 7). `saveNote` sets `n.prog` on any change made more than a minute after creation; cards then show a red dot "Avanzata oggi/ieri/N giorni fa" (grey once older than N days).
- "Pro" features are free for now but marked with the `.planBadge` label so they can be gated later.
- Brand: white background, green accent `#1e9a55`, fonts Young Serif / Figtree / JetBrains Mono.
- Do not copy AudioPen's texts, illustrations or look; functional ideas only.
